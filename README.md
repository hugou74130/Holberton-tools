## 🧐 About <a name = "about"></a>

This repository contains various tools and small projects designed to make life easier for Holberton School students. It includes a README scrapper, a skills splash page, and miscellaneous utilities.

## 🏁 Getting Started <a name = "getting_started"></a>

### Prerequisites

- Python 3.x
- A modern web browser

### Installing

Clone the repository:

```bash
git clone https://github.com/hugou74130/Holberton-tools.git
cd Holberton-tools
```

## 🔧 Tools <a name = "tools"></a>

| Tool | Description | Language |
|------|-------------|----------|
| `combat.py` | Combat simulation utility | Python |
| `Readme_holbie_scrapper/` | README scrapper for Holberton projects | Python |
| `Seahorse_skills_splash/` | Interactive skills splash page | HTML/CSS/JS |

## 🎈 Usage <a name = "usage"></a>

### Combat Tool

```bash
python3 combat.py
```

### README Scrapper

```bash
cd Readme_holbie_scrapper
python3 extract.py
```

### Skills Splash Page

Open `Seahorse_skills_splash/index.html` in your browser.

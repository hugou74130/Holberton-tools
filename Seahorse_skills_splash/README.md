# 🌊 Seahorse Skills Splash

An interactive splash page showcasing Holberton School skills with a seahorse theme.

## Files

| File | Description |
|------|-------------|
| `index.html` | Main splash page |
| `style.css` | Styling and animations |
| `script.js` | Interactive behaviors |
| `seahorse-banner.png` | Banner image |
| `holberton-logo.svg` | Holberton School logo |

## Usage

Open `index.html` in any modern web browser:

```bash
open index.html
# or
firefox index.html
```

## Preview

A visually engaging landing page with smooth animations and responsive design, themed around seahorses and ocean aesthetics.
